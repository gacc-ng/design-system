# Architecture Principles

**@gacc-ng/ui** is architected for enterprise-scale Angular applications, combining the headless accessibility power of Spartan & Angular CDK with Tailwind CSS v4 design tokens.

---

- **Brain Layer (`@spartan-ng/brain/*`):** Headless logic. Manages keyboard navigation (arrows, Home/End, Escape), focus traps, ARIA roles (`role="dialog"`, `role="combobox"`), and data attributes (`data-state="open"`). Strictly contains **no CSS or styling classes**.
- **Helm Layer (`@gacc-ng/ui/*`):** Visual presentation directives. Composed onto Brain primitives via Angular `hostDirectives`. Applies Tailwind tokens, variant switches via `cva()`, and class merging via `hlm()`.

## 2. Signal-First & Zoneless by Default

Every component in `@gacc-ng/ui` embraces modern Angular reactivity:

- **Signal Inputs (`input()` / `input.required()`):** Eliminates classical `@Input()` setters and lifecycle hook overhead.
- **Computed Expressions (`computed()`):** Derives variant class combinations lazily without unnecessary recalculations.
- **Signal Outputs (`output()`):** Modern typed event emissions without `EventEmitter` boilerplate.
- **Zoneless Compatible:** Works out of the box with `provideExperimentalZonelessChangeDetection()`, removing `zone.js` runtime overhead and change detection cycles across the whole app.

---

## 3. Secondary Entry Points

Every component is published as an isolated secondary entry point under `@gacc-ng/ui/<primitive>`:

```typescript
// Optimized: loads only the button package and its dependencies
import { HlmButton } from '@gacc-ng/ui/button';

// Clean tree-shaking: loads only the avatar package
import { HlmAvatar, HlmAvatarFallback, HlmAvatarImage } from '@gacc-ng/ui/avatar';
```

### Benefits:

- **Zero Monolithic Imports:** Unused components are never bundled into your production build.
- **Fast Build Times:** Angular partial compilation compiles and caches each entry point independently.
- **Granular Updates:** Primitives remain cleanly modular and decoupled.
