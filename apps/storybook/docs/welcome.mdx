**@gacc-ng/ui** is an accessible, composable, signal-based Angular UI primitive library built on top of [Spartan NG](https://spartan.ng) (Brain headless CDK logic + Helm visual layer), Tailwind CSS v4, and Angular CDK.

Strictly designed for modern Angular (v22+), every primitive enforces **Zoneless change detection**, **OnPush by default**, and reactive **Signals** (`input()`, `computed()`, `output()`).

---

## Architectural Highlights

- **Brain Layer (`@spartan-ng/brain/*`)**: Headless behavioral logic, Angular CDK overlays, WAI-ARIA compliance, and keyboard focus management. Strictly free of visual styles or utility classes.
- **Helm Layer (`@gacc-ng/ui/*`)**: Presentational directives applying Tailwind CSS v4 design tokens, `class-variance-authority` (`cva()`), and the `hlm()` merging helper (`clsx` + `tailwind-merge`).
- **Signal-First Reactivity**: Native Angular signals for all inputs and state transitions, eliminating `zone.js` runtime overhead.
- **Secondary Entry Points**: Every primitive is packaged independently under `@gacc-ng/ui/<primitive>` for fine-grained tree-shaking and isolated imports.

## Installation

### 1. Peer Dependencies

Install the core peer dependencies in your consuming Angular workspace:

```bash
pnpm add @angular/cdk @angular/forms @spartan-ng/brain class-variance-authority clsx tailwind-merge tailwindcss tw-animate-css
```

### 2. Library Package

Install the `@gacc-ng/ui` package:

```bash
pnpm add @gacc-ng/ui
```

---

## Global CSS Setup

Add Tailwind CSS v4 and the unified `@gacc-ng/ui` preset to your root stylesheet (e.g. `src/styles.css`):

```css
@import 'tailwindcss';
@import '@gacc-ng/ui/preset.css';
```

> The unified preset automatically configures `@source` scanning for Tailwind CSS v4, supplies the full OKLCH color token palette (light & dark mode), sets up CDK overlay positioning, and integrates tw-animate-css keyframes.

---

## Application Configuration

Register the core UI provider and zoneless change detection in your application entry point (`app.config.ts`):

```typescript
import { ApplicationConfig, provideExperimentalZonelessChangeDetection } from '@angular/core';
import { provideSpartanHlm } from '@gacc-ng/ui/utils';

export const appConfig: ApplicationConfig = {
    providers: [provideExperimentalZonelessChangeDetection(), provideSpartanHlm()],
};
```

## Usage Example

Import primitives from their isolated secondary entry points. Here is a standard button composition using `HlmButtonDirective` with `variant` and `size` inputs:

```typescript
import { Component } from '@angular/core';
import { HlmButtonDirective } from '@gacc-ng/ui/button';

@Component({
    selector: 'app-example',
    standalone: true,
    imports: [HlmButtonDirective],
    template: `
        <div class="flex items-center gap-3">
            <button hlmBtn variant="default" size="default">Primary Action</button>
            <button hlmBtn variant="secondary" size="default">Secondary</button>
            <button hlmBtn variant="outline" size="sm">Small Outline</button>
        </div>
    `,
})
export class ExampleComponent {}
```

## Font Installation & Typography

The design system uses a high-performance system font stack via the `--font-sans` token by default:

```css
--font-sans: -apple-system, BlinkMacSystemFont, 'Segoe UI', Roboto, 'Helvetica Neue', Arial, 'Noto Sans', sans-serif;
```

To use a custom font family like **Geist**, **Inter**, or **Figtree**, load the font in your `index.html` or root stylesheet and override `--font-sans`:

```html
<link rel="preconnect" href="https://fonts.googleapis.com" />
<link rel="preconnect" href="https://fonts.gstatic.com" crossorigin />
<link href="https://fonts.googleapis.com/css2?family=Geist:wght@300;400;500;600;700&display=swap" rel="stylesheet" />
```

```css
@theme {
    --font-sans: 'Geist', sans-serif;
}
```

## Theming & Design Tokens

Styling is driven by OKLCH CSS custom properties supporting dynamic theme switching and radius scaling:

- **Light & Dark Mode**: Toggle the `.dark` class on the root `<html>` element. Both light and dark palettes are baked into `@gacc-ng/ui/preset.css`.
- **Border Radius Presets**: The `--radius` variable scales all component corners (`--radius-sm`, `--radius-md`, `--radius-lg`, `--radius-xl`). Use the Storybook toolbar radius picker to test variations in real time.
- **OKLCH Tokens**: Full contrast-compliant system tokens for `--background`, `--foreground`, `--primary`, `--secondary`, `--muted`, `--accent`, `--destructive`, `--border`, and `--ring`.

## Component Metadata & AI Tooling (Storybook MCP)

This Storybook instance is connected to the **Model Context Protocol (MCP)** via `@storybook/addon-mcp`, allowing AI assistants (like Antigravity, Claude, or Cursor) to inspect components, query live props, and preview stories directly:

- **SSE Endpoint**: `http://localhost:4400/mcp`
- **Core MCP Tools**:
    - `docs-list`: Discover registered components and documentation pages.
    - `docs-show`: Query component documentation, input signatures, and argTypes.
    - `docs-show-story`: Retrieve code and template configuration for any story variant.
    - `stories-preview`: Generate live preview URLs for rendered components.
