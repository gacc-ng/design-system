# Theming & Design Tokens

**@gacc-ng/ui** uses OKLCH color spaces and CSS custom properties for uniform, accessible contrast across Light and Dark themes.

---

## 2. Dark Mode Configuration

Dark mode activates whenever the `.dark` class is applied to the root element (`<html>` or `<body>`).

```html
<!-- Light Mode -->
<html lang="en">
    ...
</html>

<!-- Dark Mode -->
<html lang="en" class="dark">
    ...
</html>
```

### Programmatic Toggle

```typescript
function toggleDarkMode(enableDark: boolean): void {
    document.documentElement.classList.toggle('dark', enableDark);
}
```

## 3. Dynamic Corner Radius (`--radius`)

The entire component catalog scales its rounded corners based on the single `--radius` CSS variable (default: `0.625rem` / `10px`).

The preset automatically derives all sub-radii:

- `--radius-sm`: `calc(var(--radius) * 0.6)`
- `--radius-md`: `calc(var(--radius) * 0.8)`
- `--radius-lg`: `var(--radius)`
- `--radius-xl`: `calc(var(--radius) * 1.4)`
- `--radius-2xl`: `calc(var(--radius) * 1.8)`
- `--radius-3xl`: `calc(var(--radius) * 2.2)`
- `--radius-4xl`: `calc(var(--radius) * 2.6)`

To change the corner curvature application-wide:

```css
:root {
    --radius: 0.75rem; /* 12px rounded aesthetic */
}
```

## 4. Typography & Font Stacks

By default, `@gacc-ng/ui` uses a high-performance system font stack:

```css
--font-sans: -apple-system, BlinkMacSystemFont, 'Segoe UI', Roboto, 'Helvetica Neue', Arial, 'Noto Sans', sans-serif;
```

To customize the font, simply override `--font-sans` in your root stylesheet:

```css
:root {
    --font-sans: 'Geist', 'Inter', sans-serif;
}
```
