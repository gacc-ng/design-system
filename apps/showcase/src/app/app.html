Design System Showcase

Atomic components validation: Button, Badge, Input & Label with full OKLCH theming and accessibility.

1. Variants (`variant`)

Visual hierarchy mapped to design tokens (`primary`, `secondary`, `destructive`, `outline`, `ghost`, `link`).

2. Sizes (`size`)

Height, padding, typography, and radius scaled across standard sizes (`xs`, `sm`, `default`, `lg`).

3. Interactive & Disabled States

Verified with `BrnButton` headless directive handling `[disabled]` attributes and ARIA attributes.

Anchor Tag as Button (<a hlmBtn>)

4. Icon Button Sizes (`icon-xs`, `icon-sm`, `icon`, `icon-lg`)

Fixed aspect ratio button sizes for standalone icon triggers.

5. Composite Actions (Text + Icons)

Buttons combining text and icons with proper gap spacing.

6. Badges (`[hlmBadge]`)

Atomic status indicators and counters with design tokens (`default`, `secondary`, `destructive`, `outline`, `ghost`, `link`).

Default Secondary Destructive Outline Ghost Link

7. Form Inputs & Labels (`[hlmInput]` + `[hlmLabel]`)

Accessible form field primitives with focus rings, sizing variants, and semantic WAI-ARIA associations.
