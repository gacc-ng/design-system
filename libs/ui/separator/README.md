# @gacc-ng/ui/separator

Separator directive and component primitive built on Spartan Brain (`BrnSeparator`) with Tailwind styling.

## Usage

```html
<!-- Horizontal Separator (Default) -->
<hlm-separator />

<!-- Vertical Separator -->
<div class="flex h-5 items-center gap-4 text-sm">
    <div>Blog</div>
    <hlm-separator orientation="vertical" />
    <div>Docs</div>
    <hlm-separator orientation="vertical" />
    <div>Source</div>
</div>
```
