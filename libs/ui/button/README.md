# @gacc-ng/ui/button

Button directive primitive built with Tailwind CSS, CVA, and Spartan Brain headless logic (`BrnButton`).

## Imports

```typescript
import { HlmButton, HlmButtonImports } from '@gacc-ng/ui/button';
```

## Usage

```html
<!-- Default button -->
<button hlmBtn>Default Button</button>

<!-- Variants: default | secondary | destructive | outline | ghost | link -->
<button hlmBtn variant="secondary">Secondary</button>
<button hlmBtn variant="destructive">Destructive</button>
<button hlmBtn variant="outline">Outline</button>

<!-- Sizes: default | sm | lg | icon -->
<button hlmBtn size="sm">Small</button>
<button hlmBtn size="lg">Large</button>

<!-- Disabled state -->
<button hlmBtn disabled>Disabled</button>
```
