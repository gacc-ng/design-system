# @gacc-ng/ui/date-picker

Accessible, headless-driven date picker components and directives based on Spartan UI (`@spartan-ng/brain/date-picker`) and Angular CDK overlay/popover primitives.

## Features

- **HlmDatePicker**: Single date picker with popover overlay and embedded calendar.
- **HlmDatePickerTrigger**: Accessible trigger button opening date picker popovers with formatted date projection.
- **HlmDatePickerInput**: Text-input based date entry with manual typing, auto-commit, and clear button.
- **HlmDatePickerMulti & HlmDateMultiInput**: Multi-date picker supporting multiple discrete selections.
- **HlmDateRangePicker & HlmDateRangeInput**: Date range picker supporting start and end date interval selections.
- **HlmMonthYearPicker & HlmMonthYearInput**: Month and year selector.
- **HlmDatePickerAnchor**: Custom overlay origin anchor directive.
- **Form Controls & CVA**: Full Angular forms `ControlValueAccessor` and Signals form interoperability.

## Installation / Usage

```typescript
import { HlmDatePickerImports } from '@gacc-ng/ui/date-picker';
```
